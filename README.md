# Music_Player
This project is a web-based music player application designed to provide a seamless,a sleek, responsive and interactive audio experience. It utilizes HTML5, CSS3, and Vanilla JavaScript to handle media streams, dynamic UI updates, and responsive design.

## Features

*   **Custom UI/UX**: Designed with a frosted-glass aesthetic and responsive layouts for desktop and mobile.
*   **Dynamic Playback**: Includes Play/Pause, Next/Previous, and Volume control functionality.
*   **Interactive Progress Bar**: Real-time progress tracking with the ability to "seek" (jump) to any part of the song.
*   **Automated Queue**: Automatically plays the next track in the playlist once the current song ends.
*   **Visual Animations**: Features a spinning vinyl record animation that synchronizes with the playback state[cite: 2].
*   **Dynamic Playlist**: The song queue is generated via JavaScript, allowing for easy updates to the song library[cite: 1].

## Technologies Used

*   **HTML5**: For semantic structure and the `<audio>` API[cite: 3].
*   **CSS3**: For advanced styling, animations, and Glassmorphism effects[cite: 2].
*   **JavaScript (ES6+)**: For audio logic, DOM manipulation, and state management[cite: 1].
